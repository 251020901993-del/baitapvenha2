Cách mở trên Mac:
1. Giải nén file ZIP.
2. Mở index.html bằng Safari hoặc Chrome để xem.
3. Mở hw1.css bằng VS Code/TextEdit nếu muốn xem hoặc chỉnh CSS.
4. Khi nộp Coursera, hãy kiểm tra đúng yêu cầu trong trang bài tập. Thông thường bài yêu cầu nộp tệp CSS hw1.css.

Lưu ý: HTML trong gói này được dựng lại theo cấu trúc/nội dung mẫu của bài để bạn có thể chạy ngay; vì không truy cập được trực tiếp tệp HTML gốc qua Coursera, hãy đối chiếu với mã HTML Homework One của bạn trước khi nộp nếu giảng viên yêu cầu giữ nguyên hoàn toàn HTML gốc.
